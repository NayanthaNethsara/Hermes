### Resolution: `<p> cannot contain a nested <div>`

#### Cause
When `ReactMarkdown` parses inline image syntax (`![caption](url)`), it wraps the element inside a paragraph (`<p>`). The custom `img` renderer previously returned a block `<div>`, creating invalid HTML nesting (`<p><div>...</div></p>`) that the DOM parser automatically breaks and React flags during hydration.

#### Fix
1. In [answer-card.tsx](file:///Users/nayanthanethsara/Documents/Github/Archivist/src/frontend/components/answer-card.tsx#L73-L146):
   - Replaced paragraph tag wrapper with `<div className="leading-relaxed ...">` in markdown renderers to allow nested blocks safely.
   - Refactored `img` custom component from a `<div>` to a valid phrasing `<span role="button" className="block ...">` container.
2. In [document-modal.tsx](file:///Users/nayanthanethsara/Documents/Github/Archivist/src/frontend/components/document-modal.tsx#L148-L153):
   - Mirrored the paragraph tag wrapper to `<div className="leading-relaxed ...">`.
